# 20년차 전문 데이터 분석가의 EDA 실무 체크리스트 및 가이드

본 문서는 `py-eda` 스킬을 활용하여 실제 데이터 분석 프로젝트를 수행할 때 참고하는 상세 지침서입니다.

---

## 1. 단계별 실행 원칙

### 1.1 초기 탐색 단계
- **원시 데이터 손상 금지**: 원본 데이터는 수정하지 않고, 복사본(`df.copy()`)을 생성하여 전처리를 수행합니다.
- **결측치 및 중복값 패턴 분석**: 단순히 결측치나 중복값을 행 삭제하기 전에, 결측이 발생한 기저 메커니즘(MCAR, MAR, MNAR)을 검토합니다.

### 1.2 시각화 원칙
- **Seaborn 스타일 금지**:
  - `sns.set_theme()`, `sns.set_style()` 등은 사용하지 않습니다.
  - Matplotlib 본연의 깔끔하고 직관적인 레이아웃을 사용하며 그리드, 축선, 레이블을 정교하게 설정합니다.
- **한글 폰트(koreanize-matplotlib)**:
  - 폰트 깨짐 방지를 위해 스크립트 최상단에서 `koreanize-matplotlib`를 필수로 임포트합니다.
- **이미지 격리 보관**:
  - 모든 이미지는 동일 경로의 `images/` 디렉토리에 분리 저장합니다.
- **차트 구성**:
  - 일변량, 이변량, 다변량 차트를 고르게 배분하여 총 10개 이상 작성합니다.
  - 모든 차트마다 교차표(`pd.crosstab`), 피봇테이블(`pd.pivot_table`), 기술통계표(`describe()`)를 함께 출력하여 시각적 직관과 정량적 수치를 동시에 제공합니다.
  - 각 시각화 차트에는 300자 이상의 20년차 시니어 분석가 심층 해석을 반드시 작성합니다.

### 1.3 텍스트 변수 분석 (TF-IDF)
- 형태소 분석기(KoNLPy 등)는 속도가 느리므로 배제합니다.
- `scikit-learn`의 `TfidfVectorizer`를 사용하여 빠르고 효율적으로 중요 단어 상위 30개를 추출하고 시각화 및 표를 출력합니다.

## 2. 자가 점검표 (Self-Audit Checklist)

분석 완료 후 아래 13개 항목을 전수 확인하십시오:

1. [ ] 가상환경: 기존 가상환경 재사용 또는 `uv` 기반 `.venv` 단일 환경 사용
2. [ ] 경로: 워크스페이스 내 상대경로 사용
3. [ ] 폰트: `koreanize-matplotlib` 임포트 완료
4. [ ] 스타일: Seaborn 스타일 함수 미사용
5. [ ] 기본 출력: `head(5)`, `tail(5)`, `info()`, `shape`, `duplicated().sum()` 출력 완료
6. [ ] 기술통계: 수치형 및 범주형 변수 모두 `describe()` 산출 완료
7. [ ] 범주형 차트: 빈도수 차트 작성 및 상위 30개 제한 적용 완료
8. [ ] 텍스트 처리: TF-IDF 기반 상위 30개 키워드 표 및 차트 작성 완료 (해당 시)
9. [ ] 이미지 저장: `images/` 폴더 내 분리 저장 완료
10. [ ] 시각화 분량: 일변량/이변량/다변량 조합 10개 이상 작성 완료
11. [ ] 동반 테이블: 모든 시각화에 교차표/피봇테이블/통계표 병행 출력 완료
12. [ ] 차트별 심층 해석: 10개 이상의 모든 시각화에 각 300자 이상의 심층 해석 작성 완료
